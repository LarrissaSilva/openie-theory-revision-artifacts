# Aviso de licenciamento

Nenhuma licença geral de reutilização é concedida por este repositório nesta versão preliminar da qualificação.

Os documentos, notebooks, scripts e planilhas autorais permanecem sob os direitos de sua autora até que uma licença seja escolhida em conjunto com a orientação e a instituição.

Materiais derivados de fontes externas permanecem sujeitos às licenças e aos direitos de seus respectivos titulares. A disponibilização de um artefato neste repositório não modifica os direitos aplicáveis à fonte original.

Antes da publicação de uma versão definitiva, recomenda-se definir separadamente:

- uma licença para código e scripts;
- uma licença para documentação;
- uma licença ou termo de uso para dados e planilhas;
- as permissões de redistribuição de exemplos provenientes do OIEC-PT-GOLD.
